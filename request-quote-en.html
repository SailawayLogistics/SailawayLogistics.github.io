Questions before requesting transport

What information should I send to request transport?

Submit loading location, unloading location, loading date, type of cargo, dimensions, weight and special loading requirements. You can add a price target if you have one, but it is not required.

Can Sailaway Logistics help with part load and full load?

Yes. Sailaway Logistics supports part loads, full loads, dedicated 3.5t van and vehicle search for European routes.

Can Sailaway Logistics help with transport documents?

Yes. Sailaway Logistics can support CMR, POD, delivery confirmation, import/export documentation and dispatch updates based on shipment.
